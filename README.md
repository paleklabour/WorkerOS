# WorkerOS - ระบบบริหารจัดการแรงงานต่างด้าวและการเงิน

ระบบบริหารจัดการฐานข้อมูลแรงงานต่างด้าว (เมียนมา, ลาว, กัมพูชา) ติดตามขั้นตอนการดำเนินงานบนแผงคัมบังบอร์ด (Kanban Board) และระบบออกใบแจ้งหนี้/ใบเสร็จรับเงินแบบรวมบิลแยกประเภทบัญชีและช่องทางเงินสด เชื่อมต่อโดยตรงกับ Google Sheets ผ่าน Google Apps Script

## 🌟 ฟีเจอร์เด่นของระบบ (Core Features)

1. **ระบบคีย์ข้อมูลนายจ้าง/ผู้รับบริการ (Customers)**: บันทึกข้อมูลบริษัท เลขผู้เสียภาษี ผู้ประสานงาน และจัดการสาขา/ที่ตั้งบริษัท
2. **ระบบฐานข้อมูลคนงานต่างด้าว (Workers)**: บันทึกข้อมูลประวัติทั่วไป, ประวัติพาสปอร์ต/CI, พ่อแม่ พร้อมระบบแนบไฟล์เอกสาร
3. **ระบบสแกนเอกสารอัตโนมัติ (AI OCR)**: แนบไฟล์ภาพหรือ PDF ใบแทนอนุญาตทำงาน (1.1) หรือพาสปอร์ต (1.2) แล้วระบบจะถอดข้อความกรอกข้อมูลลงช่องแบบอัตโนมัติผ่าน Gemini 1.5 Flash API
4. **ระบบลบฉากหลังรูปคนงาน (Background Removal)**: ถ่ายรูปหน้าตรงคนงานอัปโหลดขึ้นระบบเพื่อลบฉากหลังตัดเป็นพื้นหลังสีขาวล้วนอัตโนมัติพร้อมใช้งานทำบัตร
5. **แผงติดตามความคืบหน้างาน (Kanban Operations)**: ลากย้ายการ์ดควบคุมขั้นตอนงาน (รอดำเนินการ, กำลังดำเนินการ, รอเอกสาร, เสร็จสิ้น) พร้อมสถานะบัญชีการเงินที่แยกอย่างชัดเจน
6. **ระบบออกใบแจ้งหนี้รวมบิล (Combined Invoice Aggregator)**: ติ๊กเลือกรวมหลายงานย่อยของนายจ้างรายเดียวกันมาออกบิลใบแจ้งหนี้/ใบเสร็จใบเดียว โดยระบบจะยุบประเภทงานบริการเดียวกันคำนวณราคาทวีคูณ และระบุประวัติคนงานแยกแถวในคำอธิบาย
7. **แดชบอร์ดสรุปรายรับการเงิน (Finance Stats Dashboard)**: สรุปยอดประมาณการรายรับ, ยอดชำระแล้ว, ยอดคงเหลือค้างจ่าย, ยอดรายรับสะสมแยกประเภทงานที่แจ้ง, ยอดการเงินแยกตามธนาคาร และยอดรับเงินสด

## 📂 โครงสร้างไฟล์ในโครงการ (Project Structure)

* `index.html` - หน้าต่างหลักและโครงสร้างของแอปพลิเคชัน
* `styles.css` - สไตล์การแสดงผล ดีไซน์ธีม และตารางการจัดวางตำแหน่ง
* `app.js` - โค้ดโปรแกรมด้านหน้า ควบคุมตรรกะ ปุ่มกด และการทำรายการฝั่งลูกข่าย
* `Code.gs` - รหัสเชื่อมต่อฝั่งเซิร์ฟเวอร์คลาวด์ เขียนข้อมูลลงชีต เชื่อมต่อ Google Drive และ Gemini API
* `ARCHITECTURE.md` - แผนผังสถาปัตยกรรมระบบโดยละเอียดและการเชื่อมโยงข้อมูล
* `apps-script/` - โฟลเดอร์รวมไฟล์ที่ถูกแยกประกอบร่างเพื่อนำไป Copy-Paste อัปโหลดขึ้น Google Apps Script
* `bundle-gas.ps1` - สคริปต์ PowerShell สำหรับรวบรวมไฟล์ฝั่งเครื่องโลคอลส่งออกไปเป็นเวอร์ชันสำหรับ Apps Script ภายใน 1 วินาที
