# คู่มือการติดตั้งระบบหลังบ้าน Google Sheets + Google Drive + Line OA

คู่มือนี้แนะนำขั้นตอนในการเปลี่ยนระบบบริหารจัดการคนงานต่างด้าวต้นแบบของคุณ ให้ทำงานออนไลน์และเชื่อมต่อกับระบบคลาวด์ของ Google และ Line OA

---

## 1. การเตรียม Google Sheets และ Google Drive

### ขั้นตอนที่ 1: สร้าง Google Sheets
1. ไปที่ [Google Sheets](https://sheets.google.com/) แล้วสร้าง Spreadsheet ใหม่
2. เปิดหน้า Spreadsheet ขึ้นมา และคัดลอก **Spreadsheet ID** จากแถบที่อยู่ (URL) ของเบราว์เซอร์:
   * เช่น `https://docs.google.com/spreadsheets/d/1XyZ_this_is_spreadsheet_id_abc123/edit`
   * ID คือ `1XyZ_this_is_spreadsheet_id_abc123`
3. ใน Spreadsheet ให้สร้างแท็บ/ชีตย่อยไว้ดังนี้ (พิมพ์ชื่อสะกดให้ตรงตัวพิมพ์เล็ก-ใหญ่):
   * `Users` (สำหรับสมาชิกผู้ใช้งานล็อกอิน)
   * `Customers` (ข้อมูลนายจ้าง/ผู้ว่าจ้าง)
   * `Workers` (ข้อมูลคนงานต่างด้าว)
   * `Jobs` (ระบบแจ้งงานและออกบิล)
   * `Banks` (บัญชีธนาคารรับเงิน)
   * `Line_Groups` (กลุ่มไลน์ที่ผูกไว้แจ้งเตือน)
   * `Line_Logs` (บันทึกประวัติข้อความจาก Line)

### ขั้นตอนที่ 2: เตรียมโฟลเดอร์ Google Drive
1. ไปที่ [Google Drive](https://drive.google.com/) แล้วสร้างโฟลเดอร์ใหม่ เช่นตั้งชื่อว่า `ระบบเอกสารต่างด้าว`
2. ดับเบิ้ลคลิกเข้าโฟลเดอร์นั้น แล้วคัดลอก **Folder ID** จาก URL เบราว์เซอร์:
   * เช่น `https://drive.google.com/drive/folders/1aBc_this_is_folder_id_xyz456`
   * ID คือ `1aBc_this_is_folder_id_xyz456`
3. กำหนดสิทธิ์ให้โฟลเดอร์นี้เป็น "ทุกคนที่มีลิงก์มีสิทธิ์อ่าน" (Anyone with the link can view) เพื่อให้ระบบหน้าบ้านแสดงรูปภาพหรือพาสปอร์ตของแรงงานได้

## 2. การสร้างและติดตั้ง Google Apps Script

1. ในหน้า Google Sheets ที่คุณสร้างไว้ ให้ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ระบบจะเปิดหน้าต่างแก้ไขสคริปต์ขึ้นมา ให้ลบโค้ดเริ่มต้นออกทั้งหมด
3. คัดลอกโค้ดทั้งหมดในไฟล์ `Code.gs` ที่ถูกสร้างขึ้นมาในโฟลเดอร์นี้ ไปวางในหน้าแก้สคริปต์ของ Google
4. แก้ไขตัวแปรในส่วน **CONFIGURATION** (บรรทัดต้นไฟล์):
   ```javascript
   var SPREADSHEET_ID = "ใส่ ID Google Sheet ที่คุณก๊อปปี้มา";
   var MAIN_DRIVE_FOLDER_ID = "ใส่ ID โฟลเดอร์ Google Drive ที่คุณก๊อปปี้มา";
   ```
5. **ตั้งค่า API Key/Token แบบปลอดภัย (ห้ามพิมพ์ใส่ในไฟล์โค้ดโดยตรง):**
   * ในหน้า Apps Script Editor คลิกไอคอนเฟือง ⚙️ (Project Settings) ที่เมนูซ้าย
   * เลื่อนลงไปหาหัวข้อ **Script Properties** > กด **Add script property**
   * เพิ่ม 2 รายการ:
     * Property: `GEMINI_API_KEY` — Value: คีย์จาก Google AI Studio
     * Property: `LINE_CHANNEL_ACCESS_TOKEN` — Value: Token ของ Line OA (ถ้ามี)
   * กด **Save script properties**
   * โค้ดจะดึงค่าเหล่านี้อัตโนมัติผ่าน `getScriptProp_()` — ไม่ต้องแก้อะไรในไฟล์ `Code.gs` อีก
6. กดปุ่มบันทึก 💾 (Save Project) ด้านบน

⚠️ **สำคัญมาก**: บัญชีเริ่มต้น (`admin@system.com` / `manager@system.com` / `staff@system.com`) ที่ระบบสร้างให้อัตโนมัติในชีต `Users` ตอนรันครั้งแรก ใช้รหัสผ่านเริ่มต้นที่คาดเดาได้ง่าย **ให้เข้าไปเปลี่ยนรหัสผ่านทั้ง 3 บัญชีในชีต Users ทันทีหลังติดตั้งเสร็จ** ก่อนเปิดให้ทีมงานใช้งานจริง

## 3. ดีพลอยสคริปต์เป็น Web App เพื่อใช้เป็น API

1. ในหน้า Apps Script ให้คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)**
2. ในป๊อปอัพ ให้คลิกรูปฟันเฟือง ⚙️ ด้านซ้าย เลือกประเภทเป็น **เว็บแอป (Web app)**
3. ตั้งค่ารายละเอียดดังนี้:
   * **คำอธิบาย (Description)**: `Migrant Worker System API v1`
   * **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (อีเมลของคุณ)` <-- สำคัญมาก เพื่อให้สคริปต์ใช้สิทธิ์ของคุณอัปโหลดเข้า Drive และแก้ไข Sheet
   * **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` <-- สำคัญ เพื่อให้หน้าบ้านสามารถส่ง Request ล็อกอินหรือบันทึกข้อมูลได้
4. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)**
5. ในครั้งแรก ระบบจะขึ้นแจ้งเตือนให้คุณอนุมัติสิทธิ์ (Authorize access) ให้กดเลือกบัญชีอีเมลของคุณ กด **Advanced > Go to Untitled project (unsafe)** และกด **Allow (อนุญาต)** เพื่อยินยอมให้สคริปต์เข้าถึง Sheets และ Drive
6. เมื่อดีพลอยสำเร็จ คุณจะได้ **URL ของเว็บแอป (Web app URL)**:
   * เช่น `https://script.google.com/macros/s/AKfycbz.../exec`
   * **ให้คัดลอก URL นี้ไว้** สำหรับนำไปใส่ในโค้ดหน้าบ้าน `app.js`

## 4. ตั้งเวลาแสกนแจ้งเตือนเอกสารหมดอายุรายวัน (Daily Expiration Alert)

หากคุณต้องการให้ระบบแสกนหาพาสปอร์ต/วีซ่าที่กำลังจะหมดอายุ แล้วส่งเตือนไปกลุ่มไลน์ทุกเช้า ให้ทำดังนี้:
1. ในหน้า Apps Script เมนูด้านซ้าย เลือกสัญลักษณ์นาฬิกา ⏰ (**Triggers / ตัวกระตุ้น**)
2. คลิกปุ่ม **+ เพิ่มตัวกระตุ้น (+ Add Trigger)** ที่มุมขวาล่าง
3. ตั้งค่าดังนี้:
   * **เลือกฟังก์ชันที่จะเรียกใช้**: เลือก `dailyExpirationAlertJob`
   * **เลือกการทำให้ออกใช้งาน**: เลือก `Head`
   * **เลือกแหล่งที่มาของเหตุการณ์**: เลือก `ตามเวลา (Time-driven)`
   * **เลือกประเภทของตัวกระตุ้นตามเวลา**: เลือก `ตัวจับเวลาแบบรายวัน (Day timer)`
   * **เลือกช่วงเวลา**: เลือก `08:00 ถึง 09:00` (หรือช่วงเวลาที่คุณสะดวก)
4. คลิก **บันทึก (Save)**

## 5. การตั้งค่า Line OA และกลุ่มแจ้งเตือน

1. เข้าสู่ระบบ [Line Developers Console](https://developers.line.biz/)
2. สร้าง Provider และสร้าง Channel ประเภท **Messaging API**
3. คัดลอก **Channel Access Token** มาใส่ในตัวแปร `LINE_CHANNEL_ACCESS_TOKEN` ใน Apps Script
4. ในส่วน **Webhook settings**:
   * ติ๊กเปิดใช้งาน **Use webhook**
   * เอา **Web app URL** ของ Google Apps Script ที่ได้จากข้อ 3 ไปใส่เป็น **Webhook URL**
   * ดึง Line OA (บอทของคุณ) เข้าไปอยู่ในกลุ่มตรวจคนงานที่คุณสร้างไว้
   * เมื่อบอทเข้ากลุ่ม ระบบ Apps Script จะล็อกและบันทึก ID กลุ่มลงในชีต `Line_Groups` โดยอัตโนมัติ ทำให้ระบบสามารถส่งข้อความหาคนในกลุ่มได้สำเร็จ!

## 6. การตั้งค่าระบบสแกนเอกสารด้วย AI Gemini (ความแม่นยำสูง)

หากคุณต้องการเปิดใช้ระบบแสกนเอกสาร (พาสปอร์ต, บัตรชมพู, วีซ่า) ด้วย AI Gemini ของ Google เพื่อความแม่นยำสูงและรองรับการแสกนจากไฟล์ภาพถ่าย (ไม่ใช่แค่ PDF):

1. ไปที่ [Google AI Studio](https://aistudio.google.com/) แล้วสร้าง **Gemini API Key** (ฟรีสำหรับสิทธิ์การใช้งานทั่วไป)
2. คัดลอก API Key ที่ได้
3. ในหน้า Apps Script ของ Google Sheet ให้นำคีย์ไปใส่ในตัวแปร `GEMINI_API_KEY` ในหน้าโค้ดหลังบ้าน (Code.gs บรรทัดที่ 11):
   ```javascript
   var GEMINI_API_KEY = "ก๊อปปี้คีย์ของท่านมาใส่ที่นี่";
   ```
4. กดบันทึกสคริปต์ 💾 และทำตามขั้นตอนการ ** Deploy ใหม่ (New Deployment) ** อีกครั้งหนึ่งเพื่ออัปเดตระบบ
5. ตอนนี้เมื่อมีการแนบไฟล์รูปถ่ายหรือสแกนพาสปอร์ต/ใบอนุญาตทำงาน ระบบจะประมวลผลผ่าน AI Gemini และสแกนกรอกข้อมูลให้อย่างรวดเร็วและแม่นยำสูงที่สุดครับ!
